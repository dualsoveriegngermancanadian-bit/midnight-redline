# Midnight Redline — Build Notes

The game runs inside a React host with Babylon.js isolated in framework-agnostic game modules. The first production target is a deterministic, accessible straight-line drag-race simulation, not a general vehicle-physics sandbox. This protects the core promise—engine modification and precise timing—while keeping race results explainable.

The art reference is reserved at `/manus-storage/fast-furious-midnight-redline-visual-target_cfd073f9.png`. It will be used as a visual reference after generation completes; its managed URL can be placed directly in the UI without committing image files to the project.

The project has a user-authorized Fast & Furious presentation. No protected character likenesses, manufacturer logos, or copied film scenes are needed for the first playable build.
